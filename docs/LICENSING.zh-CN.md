# 许可与来源确认

当前仓库历史版本没有 LICENSE，也没有明确的 README 授权声明。本次技术修复不代替原代码、第三方资料与已有贡献的权属确认，因此未擅自添加 MIT、Apache 或其他项目级许可证，也未在 POM 中声明未经确认的许可。

正式分发前，维护者需确认公司命名空间下原代码的授权、已有贡献、历史拷贝代码来源及 doc 中 PDF 的再分发条件，再选择许可证并记录相应版权和 NOTICE。公开可访问不能替代许可；参见 [GitHub 许可说明](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository)。

新密码实现调用外部 Bouncy Castle 依赖，其许可由该项目提供；本项目不复制 BC 的算法实现。测试使用标准数学向量与明确的非生产样本，来源在测试和互通说明中标识。项目级许可证确认后，应同步更新 LICENSE、POM、README 和发布检查状态。
